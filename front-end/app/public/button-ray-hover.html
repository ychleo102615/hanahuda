Style 02 雙向夾擊 · H-CW × V-CCW

上下軌維持順時針（上←左、下←右），左右軌改為逆時針（左←上、右←下）。
四條光線對向夾入：水平方向互相迎合，垂直方向也互相迎合，但兩組各自獨立旋向。
退場沿原路退回。視覺感：張力交匯、動感不規則，呼應示意圖中的「不穩定聚焦」。

退場時光線對稱收縮回中點。視覺感：最對稱、最穩定，有「充能完畢」的靜態美感。

IMPLEMENTATION NOTES — 實作交接

HTML 結構（通用）

以 .rw 包裹按鈕（position:relative; display:inline-flex），button 後插入 4 個 <span class="r r-{t|b|l|r}">。Style class（.s2 等）掛在 .rw 上。

切線進場原理

  • 光線已在正確的 Y 位（上軌 top:-1px），只需在 X 軸位移
  • 初始 translateX(-100%) 讓整條線滑出左側（-100% = 自身寬度）
  • Hover 目標 translate(0,0) 即回到定位
  • scaleX/scaleY 版同理：從 0 延展至 1，transform-origin 決定起始點

動畫 Token

  • 進場緩動：cubic-bezier(0.22,1,0.36,1) · 350ms
  • 退場緩動：cubic-bezier(0.4,0,1,1) · 390ms
  • 透明度進 160ms ease / 退 260ms ease
  • S05 筆順 delay：0 / 80 / 160 / 240ms（入），150 / 100 / 50 / 0ms（出）
  • S06 角落 delay：0 / 90 / 180 / 270ms（入），150 / 100 / 50 / 0ms（出）

S02 / S03 — 注意

translate(0,0) 可對所有軌道統一使用（對 translateX 和 translateY 都有效）。進退場只需切換一條 hover rule。

退場時光線沿「進場的反方向」退出，即原路折返，實作上只需讓 non-hover transition 接管即可。

S04 — 注意

scaleX / scaleY 的 hover rule 必須按方向分開寫（不可用 translate(0,0) 合併），否則 transform 會被覆蓋為 translate。

可選：搭配 --rail-overhang: 0px 讓中心對稱更精確。

選型建議

  • S02：最直接的「鎖定」感，推薦主要遊戲按鈕
  • S04：最對稱，適合對話框內的確認按鈕
  • S05：有節奏感，適合勝局/儀式性互動
  • S06：有機蔓延，適合探索/選牌相關按鈕
  • S03：開展感，可作為次要/返回類按鈕的對比
